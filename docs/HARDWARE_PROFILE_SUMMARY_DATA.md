## 2. Hardware Subsystem Specifications

### `bobzzite` (Default Desktop Workstation)
- **Target Hardware**: Intel Core 10th Gen+ / AMD Ryzen 3000+, Intel Arc / AMD Radeon GPUs
- **Display Server**: Wayland via KWin (`kwin_wayland`)
- **Direct Rendering**: `/dev/dri/renderD128` (RADV / Iris / ANV)
- **Audio Engine**: PipeWire Pro-Audio preset (`quantum=128`, 48kHz)
- **Game Dev Engine**: Godot 4 Forward+ (Vulkan 1.3), GLES3 fallback

### `bobzzite-deck` (Handheld Gaming & Mobile)
- **Target Hardware**: Valve Steam Deck (LCD & OLED), ASUS ROG Ally, Lenovo Legion Go
- **Display Server**: Embedded Gamescope session (`gamescope -e -w 1280 -h 800`)
- **Battery Management**: Charge threshold limiting (80%) via `bobzzite-battery`
- **Audio Engine**: PipeWire handheld buffer (`quantum=256`, 48kHz)
- **Controls**: Steam Deck Neptune controller daemon & evdev event mapper

### `bobzzite-nvidia` (NVIDIA Workstation & Studio)
- **Target Hardware**: GeForce RTX 2000 series and newer (Turing, Ampere, Ada Lovelace, Blackwell)
- **Driver Stack**: NVIDIA Proprietary DKMS/AKMOD with explicit sync (`NV_drm.modeset=1`)
- **Video Acceleration**: NVENC Hardware Encoder, NVDEC Hardware Decoder
- **Compute Acceleration**: CUDA, TensorRT, OptiX ray tracing for Blender

### `bobzzite-arm64` (ARM64 SBCs & Snapdragon Laptops)
- **Target Hardware**: Snapdragon X Elite (X1E-80-100), Rockchip RK3588, Raspberry Pi 5
- **Driver Stack**: Open-source Mesa Panfrost (Mali G610), Freedreno Turnip (Adreno)
- **Display Server**: Wayland via KWin (`kwin_wayland`)
- **Emulation**: FEX-Emu / Box64 user-space x86_64 translation for Steam games

## 3. Compliance Verification Runbook

To regenerate or assert profile compliance directly from the system CLI:

```bash
# Display terminal summary matrix
bobzzite-summary terminal

# Generate Markdown summary table
bobzzite-summary markdown

# Export consolidated JSON bundle
bobzzite-summary json > /tmp/profiles_bundle.json

# Validate profile schema assertions
bobzzite-profile-validate
```
